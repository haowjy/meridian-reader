# Release notes

One Markdown file per version: `<version>.md` (e.g. `0.1.0.md`).

## Format

An optional short title line, then bullets. Keep it friendly and jargon-free — this text
becomes:

- the **GitHub Release** body,
- the **App Store "What's New"**, and
- the **in-app What's New sheet** (via `Resources/WhatsNew.json`, generated by the release
  workflow).

## Adding notes

Write the file when cutting a release. The workflow validates that
`release-notes/<version>.md` exists and is non-empty before proceeding.
